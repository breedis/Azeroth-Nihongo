japanese.ttf is IPA UI Gothic (IPAフォント), made by the Information-technology
Promotion Agency, Japan (IPA). It is included unchanged under the IPA Font License
Agreement v1.0, which is in IPA_Font_License_Agreement_v1.0.txt next to this file.

WoW's western fonts have no Japanese characters, so the addon uses this font for
everything it writes in Japanese. If kanji still show as boxes, quit the game
completely and start it again (/reload does not pick up new font files), or use
"Next font" in the options.
